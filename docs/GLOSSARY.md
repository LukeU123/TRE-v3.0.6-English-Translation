# Team Rocket Edition: Spanish → English translation guide

Translate **meaning and tone into natural English**, not word for word. This is a Spanish fan hack of Pokémon Emerald (pokeemerald-expansion). The player is a Team Rocket recruit; the story covers Kanto, Johto, the Sevii Islands and Hoenn. Dialogue is mostly casual. Keep the villains menacing and the NPCs chatty, and use idiomatic English for Spanish slang ("mola" = "it's cool", "me lo pasé pipa" = "I had a blast").

Use **US spelling**, as the official games do (center, color, honor, realize).

**Only translate. Never change meaning, add content or "fix" the story.**

## Official names: always use the official English localisation
Keep the source's capitalisation style: if the Spanish writes a name in CAPS (CIUDAD PORTUAL), write the English in CAPS (SLATEPORT CITY). Write POKéMON / Pokémon the same way the source line does.

## Hard technical rules (the checker enforces them)
- Each line in your output is `hexoffset|English text`. Use the offset exactly as given.
- Keep every control code exactly: `{V01}` (player name), `{V02}`–`{V05}` (variables), `{C....}` (colour/pause/speaker codes, e.g. `{C1920}`, `{C0805}`, `{C09}`, `{C0850}`). Same codes, same count; move them only where English word order truly needs it.
- `\n` = new line, `\l` = scroll to a new line, `\p` = new box. Keep roughly the same box structure: **max ~36 characters per line** (the checker allows up to the longest Spanish line in that string, minimum 34). Re-wrap freely within a box.
- **Leading spaces must match exactly** (the same number of spaces at the start). Never add or remove them.
- If a line starts with stray junk characters before the real text (e.g. `ÁÁÁÁÁ`, `ÛÀÑÛ Û\n`, `Ê`, `î`, `É`), copy that junk prefix **unchanged**, then translate the rest. (For example `{C19}Ê` and `{C19}î` are speaker codes followed by an argument byte, so leave them as they are.)
- Strings marked FIXED (the number after the offset is a byte budget) cannot grow: the encoded English, plus 1 for the terminator, must fit in that many bytes. Each character costs 1 byte, `{V01}` costs 2, `{Cxxxx}` costs 1 plus its hex bytes. Abbreviate if needed. Movable strings can be any length.
- Use plain ' and " (they're converted automatically). Allowed characters: A–Z a–z 0–9, spaces and . , ! ? - … : ; ' " ( ) / & + % $ = < > ♂ ♀ é and the codes above. Avoid other accented letters (only é is safe in English).
- Skip lines that are already English, are just a Pokémon/species name that's identical in English, are debug or music labels (MUS-…, Set Party), or are clearly not text (random letters). Leave them out of your output.
- Output only lines you translated. No comments, no blank lines.
